# Advanced batch

**Advanced batch** — скрипт пакетной обработки для Adobe Photoshop. Он расширяет стандартную автоматизацию Photoshop: позволяет получать документы из папки, списка открытых файлов или Adobe Bridge, выполнять последовательность из нескольких операций и JSX-скриптов, управлять остановками внутри операций и сохранять результат по единому набору правил.

## Основные возможности

- обработка файлов из выбранной папки, открытых документов Photoshop или выделения в Adobe Bridge;
- рекурсивный поиск файлов в подпапках и фильтрация по формату;
- открытие файлов обычным способом или через Adobe Camera Raw;
- последовательность до пяти операций Photoshop и JSX-скриптов;
- временное отключение отдельных шагов без удаления из списка;
- остановки между шагами и продолжение операции после встроенной команды `Stop`;
- сохранение и повторное использование пользовательских пресетов;
- сохранение в исходную или отдельную папку с восстановлением структуры подпапок;
- экспорт в JPEG, TIFF или PSD;
- продолжение незавершённого задания после повторного запуска скрипта.

## Совместимость

Скрипт тестировался в Adobe Photoshop CC 2014 и более новых версиях.

Интерфейс автоматически выбирает русский или английский язык в соответствии с языком Photoshop. При необходимости язык можно принудительно задать в начале файла [`Advanced batch.jsx`](Advanced%20batch.jsx), изменив значение `localization` на `"ru"`, `"en"` или `"auto"`.

Дополнительные библиотеки и отдельная среда выполнения не требуются.

## Установка в Photoshop

1. Скачайте репозиторий и найдите файл [`Advanced batch.jsx`](Advanced%20batch.jsx).
2. Скопируйте его в папку сценариев Photoshop:

   **Windows**

   ```text
   C:\Program Files\Adobe\Adobe Photoshop <версия>\Presets\Scripts\
   ```

   **macOS**

   ```text
   /Applications/Adobe Photoshop <версия>/Presets/Scripts/
   ```

3. Перезапустите Photoshop.
4. Запустите **Advanced batch** через меню **Файл → Автоматизация** (`File → Automate`).

Для записи в системную папку Photoshop могут потребоваться права администратора. Без установки файл можно запустить вручную через **Файл → Сценарии → Обзор** (`File → Scripts → Browse`).

## Подготовка операций и скриптов

Перед запуском загрузите необходимые операции в панель **Операции** (`Actions`) Photoshop. Скрипт получает список доступных наборов и операций непосредственно из этой панели.

Advanced batch также может выполнять другие JSX-скрипты. Поместите нужные файлы `.jsx` в ту же папку, где находится `Advanced batch.jsx`. После этого в списке наборов появится пункт **Скрипты** (`Scripts`), а в соседнем поле — найденные файлы.

Каждый дополнительный скрипт запускается для текущего активного документа. Перед пакетной обработкой рекомендуется проверить его отдельно на копии файла и убедиться, что он:

- не требует непредусмотренного ручного ввода;
- корректно работает с активным документом;
- не закрывает документ раньше, чем Advanced batch выполнит выбранный режим сохранения.

## Источник файлов

В верхней части окна выбирается источник документов.

### Открыть папку

Обрабатывает поддерживаемые изображения из выбранной папки.

Доступные параметры:

- **обрабатывать подкаталоги** — включает рекурсивный поиск;
- **открывать следующие типы файлов** — фильтрует список по расширению; варианты формируются по фактически найденным файлам;
- **использовать ACR для поддерживаемых типов файлов** — принудительно открывает документы через Adobe Camera Raw;
- **подавлять диалоги открытия** — открывает обычные файлы без дополнительных диалогов Photoshop;
- **открыть сразу все** — загружает выбранную группу документов до начала обработки;
- **группировать по подпапкам** — при одновременном открытии ограничивает группу файлами из одной папки.

Одновременное открытие большого количества изображений увеличивает потребление оперативной памяти. Для больших заданий безопаснее обрабатывать документы по одному или включать группировку по подпапкам.

> Параметр подавления диалогов относится к обычному открытию файлов. При включённом режиме ACR интерфейс Camera Raw открывается отдельно.

### Открытые документы

Обрабатывает документы, которые уже открыты в Photoshop. Этот режим удобен для несохранённых документов или предварительно подготовленных вручную файлов.

Некоторые режимы сохранения требуют, чтобы документ уже имел путь на диске. Ограничения описаны в разделе [Сохранение результата](#сохранение-результата).

### Получить файлы из Bridge

Получает выбранные в Adobe Bridge файлы и папки. Для этого требуется дополнительная интеграция, описанная в разделе [Интеграция с Adobe Bridge](#интеграция-с-adobe-bridge).

Если в Bridge выбрана папка, параметр обработки подпапок применяется к её содержимому так же, как при обычном выборе исходной папки.

## Пресеты

Пресет сохраняет конфигурацию обработки, включая:

- параметры открытия файлов;
- список и порядок операций или скриптов;
- активность шагов и флаги остановки;
- поведение при остановках;
- режим и параметры сохранения.

Исходная папка и текущий список файлов в пресет не входят.

Элементы управления:

- **↺** — восстановить сохранённое состояние выбранного пресета;
- **Сохранить** — обновить выбранный пользовательский пресет;
- **Добавить** — создать новый пресет;
- **Удалить** — удалить выбранный пользовательский пресет.

Встроенный пресет **по умолчанию** удалить или перезаписать нельзя.

Пользовательские пресеты хранятся в файле `Advanced batch.desc` внутри папки настроек Photoshop. Этот файл можно сохранить отдельно для резервного копирования или переноса конфигурации.

## Последовательность операций

В секции **Операции** можно создать цепочку из нескольких шагов. Для каждого шага доступны следующие параметры:

- **+** — добавить строку после текущей;
- **−** — удалить строку;
- **включить** — временно включить или исключить шаг из обработки;
- первое раскрывающееся поле — набор операций Photoshop или пункт **Скрипты**;
- второе поле — конкретная операция или JSX-файл;
- **стоп** — остановить автоматический переход к следующему шагу после выполнения текущего.

Шаги выполняются сверху вниз для каждого документа. После завершения последнего активного шага применяется выбранный режим сохранения.

В одной цепочке поддерживается до пяти строк. Недоступная операция или отсутствующий JSX-файл помечаются как ошибка; перед запуском такую строку необходимо исправить или удалить.

### Автоматический запуск первой операции

Параметр **автоматически запускать первую операцию при открытии документа** подходит для полностью автоматической обработки.

Отключите его, когда первый этап должен запускаться вручную — например, если операция содержит диалог, в котором требуется индивидуально настроить параметры для каждого изображения.

### Продолжение после команды Stop

Параметр **продолжить с команды «стоп», если остановка была внутри операции** относится к команде `Stop`, записанной непосредственно в Photoshop Action.

При включённом параметре скрипт запоминает позицию остановки и пытается продолжить операцию со следующей команды. При отключённом параметре остановившаяся операция считается завершённой, после чего обработка переходит к следующему шагу.

Флажок **стоп** в строке Advanced batch и команда `Stop` внутри Photoshop Action выполняют разные задачи:

- флажок строки создаёт паузу **между** операциями;
- команда `Stop` создаёт паузу **внутри** операции Photoshop.

## Сохранение результата

После выполнения цепочки выберите один из трёх режимов.

### Ничего

Advanced batch не сохраняет и не закрывает документ. Этот режим подходит, если сохранение выполняется самой операцией или результат требуется проверить вручную.

При обработке большого количества файлов незакрытые документы остаются в Photoshop и могут занять значительный объём памяти.

### Сохранить и закрыть

Photoshop сохраняет изменения в исходный файл и закрывает документ.

Режим не работает для нового документа, который ещё ни разу не был сохранён и не имеет пути на диске.

### Сохранить как… и закрыть

Скрипт сохраняет результат в выбранном формате и закрывает документ.

Доступные параметры:

- **сохранить в другую папку** — использовать отдельный каталог вывода;
- **сохранять структуру подпапок** — повторить структуру исходных каталогов внутри папки вывода;
- **тип файла** — `jpg`, `tif` или `psd`;
- **объединить слои** — выполнить Flatten Image перед сохранением;
- ползунок JPEG — качество от 1 до 12;
- **заменять файлы при сохранении** — перезаписывать совпадающие имена.

Если замена файлов отключена, скрипт создаёт уникальные имена с числовым суффиксом: `_1`, `_2` и далее. TIFF сохраняется без сжатия.

Не существующая папка вывода создаётся автоматически, если доступна её родительская папка и у Photoshop есть права на запись.

> Перед первым запуском на рабочем наборе файлов проверьте схему сохранения на копиях. Режимы «сохранить и закрыть» и «заменять файлы» могут изменять или перезаписывать исходные данные.

### Переопределение команды «Сохранить как»

Параметр **переопределить команды «сохранить как» в последней активной операции** предназначен для Action, в котором уже записана команда **Save As**.

В этом режиме:

- последним активным шагом должна быть операция Photoshop, а не JSX-скрипт;
- операция должна содержать записанную команду **Save As**;
- формат и специфические параметры сохранения берутся из самой операции;
- папка назначения управляется настройками Advanced batch;
- последнюю операцию нельзя отключать.

Этот режим полезен, когда стандартных параметров JPEG, TIFF и PSD недостаточно и требуется формат или набор опций, записанный в Action.

## Порядок работы

1. Подготовьте и проверьте операции Photoshop и дополнительные JSX-скрипты.
2. Запустите **Advanced batch**.
3. Выберите папку, открытые документы или список из Bridge.
4. Настройте поиск файлов и способ их открытия.
5. Сформируйте последовательность операций.
6. Укажите режим сохранения и папку назначения.
7. При необходимости сохраните конфигурацию как пресет.
8. Нажмите **Начать обработку**.

Скрипт последовательно выбирает документ, выполняет все активные шаги, сохраняет результат и переходит к следующему файлу.

## Продолжение незавершённого задания

Advanced batch сохраняет текущую позицию обработки. Если Photoshop был закрыт, скрипт остановлен или задание не завершилось по другой причине, при следующем запуске появится предложение продолжить работу с сохранённой позиции.

В окне подтверждения отображаются исходный путь, количество оставшихся файлов и имя следующего файла. Для корректного продолжения не перемещайте и не переименовывайте исходные файлы до завершения задания.

При ошибке отсутствующей операции, скрипта или папки сохранения обработка приостанавливается. Исправьте причину и продолжите задание либо остановите его и создайте новую конфигурацию.

## Интеграция с Adobe Bridge

Файл [`Advanced batch for Bridge.jsx`](Advanced%20batch%20for%20Bridge.jsx) добавляет команды Advanced batch в меню **Tools** и контекстное меню миниатюр Bridge. Команда передаёт выделенные файлы и папки в Photoshop и запускает основной скрипт.

Сначала установите `Advanced batch.jsx` в Photoshop, затем скопируйте Bridge-скрипт в папку запуска Adobe:

**Windows**

```text
C:\Program Files\Common Files\Adobe\Startup Scripts CC\Adobe Photoshop\
```

**macOS**

```text
<папка Adobe Bridge>/Scripts/Startup Scripts/
```

Перезапустите Adobe Bridge и Photoshop. После этого:

1. выделите нужные файлы или папки в Bridge;
2. выберите **Tools → Advanced batch: get files from Bridge** либо одноимённую команду в контекстном меню миниатюры;
3. Photoshop запустится или перейдёт на передний план;
4. Advanced batch откроется с источником **получить файлы из Bridge**.

Bridge используется только для передачи списка файлов. Все операции и сохранение выполняются в Photoshop.

## Практические рекомендации

- Всегда тестируйте новый пресет на нескольких копиях файлов.
- Не используйте одновременное открытие всех документов для очень больших наборов изображений.
- При сохранении в другую папку включайте сохранение структуры подпапок, если в исходных каталогах встречаются одинаковые имена файлов.
- Не добавляйте в цепочку операции, которые неожиданно закрывают активный документ.
- Для полностью автоматической обработки удалите из Actions диалоги и команды `Stop`, либо заранее настройте правила их продолжения.
- Перед обновлением Photoshop сохраните резервную копию файла `Advanced batch.desc` с пользовательскими пресетами.
